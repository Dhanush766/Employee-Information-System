# Employee Information System – CLI Project

## Complete Source Code

A command-line based Employee Information System developed using Python. This project allows users to manage employee information through a simple menu-driven interface.

## Features

* Add employee information
* View employee information
* Search employee details
* Update employee information
* Delete employee information
* Menu-driven CLI interface
* Input validation

## Technologies Used

* Python
* Command Line Interface (CLI)

## Python Concepts Used

* Variables
* Data Types
* Conditional Statements
* Loops
* Functions
* Lists / Dictionaries
* Exception Handling
* File Handling
* Modular Programming

## Project Purpose

This project was developed to practice Python programming concepts and understand how employee data can be managed through a command-line application.

## How to Run

1. Download or clone the repository.
2. Open the project folder in the terminal.
3. Run the Python main file.
